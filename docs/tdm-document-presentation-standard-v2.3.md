# Padrão documental e narrativo TDM v2.3

Fonte de produto: pacote intérprete documental v2.3.

## Decisões explícitas

1. Documento macro com no mínimo quatro páginas semânticas.
2. Última página exclusiva de referências.
3. Numeração no rodapé central — adaptação deliberada do produto, não conformidade estrita com a NBR 14724.
4. Screen com folhas empilhadas no scroll.
5. Tipografia documental serifada (Georgia / Times New Roman); chrome da aplicação permanece em Inter.
6. Motor narrativo determinístico, sem IA em runtime.
7. Figuras derivadas do grafo real.
8. Nenhum conteúdo inexistente para preencher páginas.

## Escopo V1

Insumos, Atividades, Produtos, Resultados, Conexões, Riscos, Hipóteses.

Matriz: Insumo→Atividade (risco), Atividade→Produto (risco), Produto→Resultado (hipótese).
