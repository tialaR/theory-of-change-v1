Código real do projeto

Não redesenhar a animação.
Apenas enquadrá-la direito.

O preview anterior recriou o motion. Esta versão mantém o contrato real encontrado no ZIP: stroke-dashoffset de 22 unidades, duração de 4.8s, repetição infinita e easing linear. A mudança proposta fica somente na moldura externa, no padding e no viewport interno.

Causa 1 · wrappers diferentes Fluxo usa previewViewport + previewStage; Resultado usa dedicatedPreviewFrame direto.
Causa 2 · aspect ratio divergente Fluxo renderiza viewBox 1520 × 800 dentro de uma moldura 1520 × 660, gerando folga vertical.
Causa 3 · padding assimétrico Fluxo adiciona 2rem no eixo Y; Resultado não possui essa camada intermediária.
